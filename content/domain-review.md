이 블로그는 Vercel의 기본 배포 주소에서 시작해 현재 대표 주소인 `https://sooyoung.pe.kr`을 사용하고 있다. 사이트맵 제출과 URL 검사에서 오류를 겪으며 개인 도메인을 연결했지만, **오류가 발생한 원인과 도메인 변경 뒤 관찰한 결과는 구분해야 한다.**

> 2026년 10월 8일 정정: `vercel.app` 전체가 Google의 극단적인 크롤링 제한을 받는다는 주장은 확인할 근거가 없어 삭제했다. 개인 도메인이 색인 생성이나 애드센스 승인의 필수 조건이라는 설명도 바로잡았다.

## 도메인을 바꾸면서 실제로 달라지는 것

개인 도메인은 방문자에게 보여 줄 대표 주소를 직접 관리할 수 있게 한다. 호스팅을 바꾸더라도 같은 주소를 유지하기 쉽고, 로그인 콜백과 공유 링크를 한 도메인 기준으로 정리할 수 있다. 하지만 도메인 구매만으로 검색 노출이나 광고 승인이 보장되지는 않는다.

기존 기록에는 사이트맵 ‘가져올 수 없음’과 URL 검사 요청의 할당량 초과가 있었다. 이런 메시지에는 접근 오류, 응답 형식, 속성 범위, 일시적인 처리 상태 등 여러 원인이 있을 수 있다. 당시 기록만으로 특정 호스팅 도메인에 대한 제재였다고 결론 내릴 수는 없다.

## Vercel과 DNS 설정

1. Vercel 프로젝트의 도메인 설정에 사용할 도메인을 추가한다.
2. Vercel이 **현재 그 프로젝트에 표시하는** DNS 레코드를 확인한다.
3. 도메인 공급자의 DNS 설정에서 해당 레코드를 등록한다. 루트 도메인과 `www` 주소는 요구하는 레코드가 다를 수 있다.
4. 충돌하는 기존 레코드가 없는지 확인하고 Vercel의 도메인 검증 상태를 확인한다.
5. HTTPS 접속과 인증서 발급이 완료됐는지 실제 주소에서 점검한다.

이 블로그의 공급자는 호스팅케이알이지만 다른 공급자에서도 원리는 같다. 과거 글의 IP 주소를 그대로 복사하지 않고 대시보드의 최신 값을 사용한다. DNS 전파와 인증서 발급 시간은 환경마다 다르므로 10~20분 안에 반드시 완료된다고 가정하지 않는다.

## 대표 주소를 바꿀 때 함께 바꿀 설정

| 항목 | 이 블로그에서 확인할 위치 |
| --- | --- |
| 메타데이터 기본 도메인 | 루트 레이아웃의 `metadataBase` |
| 글별 대표 주소 | 글 상세 `generateMetadata`의 canonical과 Open Graph URL |
| 사이트맵 | `sitemap.xml`의 글·카테고리 주소 |
| 로그인 | `NEXTAUTH_URL`과 GitHub OAuth 콜백 |
| 이전 주소 | 대표 도메인으로의 리디렉션과 최종 응답 |
| 외부 링크 | 스토어·소개 페이지·기존 공유 링크 |

NextAuth의 이 프로젝트 설정을 기준으로 운영 GitHub 콜백은 다음 경로를 사용한다.

```text
https://sooyoung.pe.kr/api/auth/callback/github
```

브라우저가 새 주소로 돌아오는지, 로그인 뒤 관리 권한이 유지되는지도 실제로 확인해야 한다. 일반 로그인 성공과 관리자 권한을 얻는 것은 다른 조건이다.

## 사이트맵 제출과 색인 확인은 다른 단계

Search Console에 대표 도메인의 소유권을 확인한 뒤 전체 사이트맵 주소를 제출한다.

```text
https://sooyoung.pe.kr/sitemap.xml
```

사이트맵 제출 ‘성공’은 Google이 사이트맵을 처리할 수 있었다는 의미다. 발견된 URL 개수가 표시되더라도 모든 페이지가 색인됐거나 검색에 노출된 것은 아니다. 대표 글 하나를 URL 검사로 확인하고 마지막 크롤링 시각, 사용자 선언 표준과 Google 선택 표준을 함께 살펴본다.

이전 주소가 새 대표 주소로 리디렉션되는 경우 이전 주소의 ‘리디렉션이 포함된 페이지’ 제외는 정상일 수 있다. 이동 전후 주소를 각각 검사해 실제 방문자가 올바른 글에 도착하는지 확인하는 것이 우선이다.

## 광고 준비에서 도메인의 역할

대표 주소, 정상적인 HTTPS 접속, 읽을 수 있는 콘텐츠와 일관된 내부 링크는 운영 기반이다. 애드센스에서는 사이트 확인과 콘텐츠 심사가 별도로 필요하다. DNS 연결이나 색인 오류 한 가지를 해결했다고 품질 심사까지 해결됐다고 보지는 않는다.

광고 수익화를 계획한다면 도메인 비용뿐 아니라 호스팅 이용 조건도 확인한다. Vercel Hobby는 비상업적 개인 용도로 제한되므로 실제 요금제와 광고 운영 목적이 맞는지 확인한 뒤 수익화를 진행해야 한다. 요금제 변경은 비용이 발생하는 별도 결정이다.
