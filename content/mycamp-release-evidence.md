## 실제 화면으로 보는 현재 서비스

아래 이미지는 이번캠 프로젝트의 Google Play 제출용 실제 화면이다. 웹과 앱이 공유하는 검색·상세·플랜·피드 흐름을 보여 준다. 캡처에 보이는 후기, 날짜와 건수는 당시 화면의 데이터이며 현재 운영 데이터와 다를 수 있다.

![이번캠 캠핑장 이름·지역 검색 화면](/images/mycamp/03-search.png)

검색 결과에서 캠핑장 이름, 주소와 사진을 확인하고 상세 화면으로 이동한다. 공공데이터와 저장된 정보는 예약 재고가 아니므로, 실제 운영 시간이나 가격은 캠핑장 측에 다시 확인해야 한다.

![이번캠 캠핑장 상세와 저장·플랜 담기 화면](/images/mycamp/04-camp-detail.png)

상세 화면에서 지도와 홈페이지를 확인한 뒤 장소를 저장하거나 플랜에 담는다. ‘예약’은 캠핑장 측의 외부 안내로 이동하는 연결이며 이번캠이 실시간 예약 가능 여부를 보장하는 기능은 아니다.

![이번캠 공개 캠핑 플랜과 후보 비교 화면](/images/mycamp/02-plans.png)

플랜은 ‘가보고 싶은 장소’를 묶는 단계다. 방문 이후 남기는 기록과 분리해, 아직 가지 않은 장소를 방문 후기처럼 보이지 않게 한다. 로그인한 사용자는 자신의 플랜을 관리하고 공개 플랜을 참고할 수 있다.

![이번캠 사진·날짜·장소를 연결한 캠핑 기록 피드](/images/mycamp/01-feed.png)

피드는 다녀온 뒤 남기는 사진과 장소 기록이다. 검색에서 찾은 장소, 플랜에 담은 후보, 실제 방문 기록이 연결되는 것이 이번캠의 중심 사용 흐름이다.

## Android 출시 이후에도 구분해서 점검할 것

[Google Play의 이번캠](https://play.google.com/store/apps/details?id=com.mycamplog.app)에서도 앱을 받을 수 있다. Android가 출시됐다는 사실과 모든 기기에서 기능이 동일하게 동작한다는 주장은 다르다. 출시 뒤에는 다음 조건을 나눠 확인해야 한다.

| 확인 영역 | 재현 조건과 기대 결과 |
| --- | --- |
| 로그인 복귀 | 앱에서 소셜 로그인 후 외부 브라우저에서 앱으로 돌아오는지 확인 |
| 세션 유지 | 로그인 후 앱을 완전히 종료하고 다시 열었을 때 세션이 유지되는지 확인 |
| 사진 권한 | 허용·거부 상태 각각에서 업로드가 동작하거나 안내가 표시되는지 확인 |
| 화면 영역 | 상태바, 노치, 키보드와 하단 탐색 영역이 입력·버튼을 가리지 않는지 확인 |
| 연결 오류 | 네트워크가 끊겼을 때 빈 화면 대신 복구 가능한 상태를 제공하는지 확인 |

이는 출시 후 점검 기준이며, 모든 기기에서 이미 통과했다는 시험 결과를 의미하지 않는다. 현재 `capacitor.config.ts`는 서버 주소를 환경 변수에서 읽고, 네이티브 쿠키 저장과 연결 오류 화면을 설정한다. 웹 코드 배포와 네이티브 플러그인 변경은 배포 방법이 다르므로 플러그인이나 권한 변경 시 앱을 다시 빌드하고 검증해야 한다.

웹·iOS·Android 링크와 전체 기능 흐름은 [이번캠 서비스 소개](/apps/mycamp)에 함께 정리했다.
